DELIVERABLE 4 · ANNOTATIONS
Owner vs watcherRole is per pet and comes with each pet object. Watchers see the same screens with owner controls not rendered (Edit pet, rule edit/delete, Add task, Watchers block, Invite). A “Watching” badge, “Owned by …” and one plain sentence explain why. Schedule is identical for both.
Disabled logicButtons are disabled only for system reasons (offline, upload in progress, request in flight) and always show the reason directly beneath. Validation never disables Save — tapping it reveals the error. Loading = spinner + verb (“Saving…”).
What's tappableTask rows, pet cards, chips, segments, tab items, icon buttons (all ≥ 44pt), links (underlined). Not tappable: badges, type tags, section headers, “Nothing scheduled”, watcher rule rows.
AssumptionsAna owns Rex and watches Miso (owned by Sam); watcher frames are signed in as Sam. “Now” is Wed 30 Sep, 13:10. Invites last 7 days. Photos are striped placeholders — drop in real ones.
